Учебная среда для выполнения кода на Python

тарапо.ру — студенческий образовательный проект. Это интерактивная песочница, в которой можно писать и запускать код на Python прямо в браузере, без установки интерпретатора на компьютер.

Перейти в редактор → Что это за проект
Честно о терминах. Python — интерпретируемый язык. Код не компилируется в машинный, а выполняется интерпретатором построчно. Поэтому мы сознательно называем тарапо.ру не «компилятором», а средой для выполнения кода — так корректнее и с точки зрения информатики, и с точки зрения учебной программы.

О проекте

Проект создан как учебный инструмент для студентов, изучающих основы программирования на Python. Цель — дать возможность запускать код на любом устройстве: в аудитории, дома, с планшета или ноутбука, — не тратя время на настройку окружения.

Среда поддерживает ввод данных через stdin, что позволяет решать учебные задачи с чтением входных данных и проверкой вывода.

Без установки

Всё работает в браузере. Не нужно ничего скачивать и настраивать пути к интерпретатору.

Ввод через stdin

Поддерживается чтение входных данных — как в задачах по олимпиадному программированию.

Понятный вывод ошибок

Трассировка выводится в отдельной консоли, чтобы было проще разбираться в причинах сбоя.

Учебный фокус

Никаких лишних настроек и плагинов: только редактор, консоль и stdin.

Ввод данных (stdin)

Среда поддерживает ввод через stdin. Данные передаются в программу через отдельное текстовое поле в редакторе. Пример чтения имени: 

import sys
name = sys.stdin.readline()
print("Привет, " + name)

Справочник по синтаксису

1. Условия (if / elif / else)

Используется, когда нужно выполнить действия в зависимости от условия.

if condition:
    # код
elif other:
    # код
else:
    # код
Важно: в Python отступы — часть синтаксиса. Ошибка в отступе приводит к IndentationError.

2. Цикл for

Перебор элементов коллекции или строки.

phones = ("iPhone", "Pixel", "Samsung")
for p in phones:
    print(p)

3. Цикл while

Применяется, когда число итераций заранее неизвестно.

while condition:
    # код

Коллекции

В Python четыре основных типа коллекций.

1. Список (list)

Упорядоченная изменяемая коллекция. Задаётся в квадратных скобках.

mylist = ["iPhone", "Pixel", "Samsung"]
print(mylist)

2. Кортеж (tuple)

Упорядоченная неизменяемая коллекция. Задаётся в круглых скобках.

myTuple = ("iPhone", "Pixel", "Samsung")
print(myTuple)

3. Множество (set)

Неупорядоченная неиндексируемая коллекция. Задаётся в фигурных скобках.

myset = {"iPhone", "Pixel", "Samsung"}
print(myset)

4. Словарь (dict)

Пары «ключ — значение». Изменяемый, индексируемый по ключу.

mydict = {
    "brand": "iPhone",
    "model": "iPhone 11"
}
print(mydict)
